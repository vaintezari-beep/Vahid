# Vahidullah Intezari Pro

یک وب‌سایت فارسی و راست‌چین برای گردآوری پرومپت‌ها، ایده‌ها و تمپلیت‌های کاربردی برای CapCut، ChatGPT و VN Editor.

## اجرا

فایل `index.html` را در مرورگر باز کنید. پروژه به فریم‌ورک یا فرایند build نیاز ندارد.

## امکانات

- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- محتوای فارسی با چیدمان راست‌چین
- فیلتر دسته‌بندی و جست‌وجوی منابع
- دکمهٔ کپی برای پرومپت‌ها و راهنماها
